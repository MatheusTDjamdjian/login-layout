# Login Layout

Tela de login responsiva em HTML, CSS e JavaScript puros.

## Recursos

- Layout split-screen com painel de imagem e formulário
- Floating labels e validação visual de e-mail
- Toggle mostrar/ocultar senha
- Aviso de Caps Lock
- Saudação por horário (Bom dia / Boa tarde / Boa noite)
- Responsivo (mobile, tablet, desktop)

## Estrutura

```
login-layout/
├── index.html
├── script.js
├── estilos/
│   ├── style.css
│   └── media-query.css
└── imagens/
    └── pexels-marcela-toledo-5610083.jpg
```

## Como usar

Abra o `index.html` no navegador ou rode um servidor local:

```bash
python -m http.server 8080
```
